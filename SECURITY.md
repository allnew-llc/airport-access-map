# Security policy

## Reporting a vulnerability

Please do not disclose a vulnerability in a public issue.

Send the affected version, reproduction steps, expected impact and a safe contact address to `info@allnew.work`. Do not include live credentials, personal data or third-party secrets.

We will acknowledge the report, investigate the affected scope and coordinate disclosure when a fix is available. This project does not offer a bug bounty unless agreed in writing before testing.

## Supported version

Security fixes are applied to the latest commit on the default branch. The public demo contains fictional transport and weather data; it is not an emergency response service.
