# 海外旅行者の空港アクセス判断

## この画面が担う判断

Airport Access Mapの役割は、地図を見せることではなく、海外旅行者が30〜60秒で「どの移動手段を比較するか」「空港へ向かうか」「空港に滞在する場合に何を利用できるか」を把握できるようにすることです。最新情報の確認先として、空港、交通事業者、行政機関の公式サイトも案内します。

画面の最初には、移動方向の選択より先に交通・気象の全体像を置きます。対象空港ごとに、鉄道または接続交通、空港バス、道路、気象、空港からのお知らせを整理します。

実データを接続する場合の状態表示には、次のEvidence Gateを適用します。

- 公式情報から現在状態を取得・判定できた場合だけ、平常・遅延・運休を表示する。
- ページへの到達確認だけでは平常と表示しない。
- 運行会社ごと・行先ごとに状態が異なるバスは、一括して「運行中」と表示しない。空港の全路線案内に加え、東京空港交通のリアルタイム所要時間と京成バスグループの運行情報へ直接誘導する。
- ユーザー向け状態は「正常」「遅延・規制」「見合わせ・通行止め」の3種類とする。取得失敗や期限切れは内部のAndon状態として保持し、画面の状態バッジには出さない。
- 利用条件や取得状況により状態を掲載できない交通機関は、状態バッジを表示せず、名称・対象路線と公式情報への直接リンクを表示する。
- 最終更新から30分以上経過した場合は、画面全体をSTALEとして公式確認を要求する。

## Journey 1: 空港に到着した旅行者

旅行者の問いは「空港を出られるか」だけではありません。

1. 到着便、到着ターミナル、荷物受取場所に変更はないか。
2. 東京・上野・新宿・横浜・千葉など目的地まで、どの交通系統が動いているか。
3. JRと京成、鉄道とバスのように、一方が止まっても使える別系統はあるか。
4. 切符を買う前に、乗り場、運行状況、終電・最終便をどこで確認するか。
5. 深夜、運休、道路規制により移動を見合わせる場合、空港のどこで待てるか。
6. Wi-Fi、充電、休憩、シャワー、宿泊、車いす対応をどこで確保できるか。
7. 日本語が分からない状態で、誰に何語で相談できるか。

画面は「空港から移動」を選ぶと、交通機関別の状態、対象区間、理由、代替候補を提示します。

## Journey 2: 空港へ向かう旅行者

旅行者の問いは「空港まで行けるか」だけではありません。

1. 出発便は予定どおりか。航空会社、ターミナル、チェックイン締切はどれか。
2. 現在地から空港まで、鉄道・バス・道路のどの系統が動いているか。
3. 一つ目が止まった場合の第二ルートを確保できるか。
4. 乗換・道路渋滞・ターミナル移動を含め、余裕時間をどれだけ持つべきか。
5. 到着が難しい場合、空港へ向かう前にどの航空会社窓口へ連絡するか。
6. 空港に早く着いた、または便が変更された場合にどこで待てるか。
7. 緊急時、移動支援が必要な場合にどこへ相談するか。

画面は「空港へ移動」を選ぶと、空港方面の交通機関別の状態、対象区間、理由、代替候補を提示します。

## 情報設計と一次情報

| 旅行者が知りたいこと | 画面上の導線 | 公式一次情報 |
|---|---|---|
| 到着便・出発便 | 空港公式情報 | 各空港のフライト検索 |
| 航空会社・ターミナル | 空港公式情報 | 各空港の航空会社・ターミナル案内 |
| 鉄道・バス・タクシー | 交通機関別の状態と公式ボタン | 各空港のアクセス案内、各交通事業者 |
| 災害・施設影響 | 空港からのお知らせ、地図 | 各空港、気象庁、自治体、国・交通事業者 |
| 深夜早朝・空港内待機 | 空港に滞在 | 各空港の早朝・深夜案内 |
| Wi-Fi・充電・休憩・宿泊 | 空港に滞在 | 各空港のサービス案内 |
| 多言語の緊急支援 | 緊急時・支援 | 日本政府観光局 訪日旅行者ホットライン |
| 警察・救急・消防 | 緊急時・支援 | 日本政府観光局 緊急時案内 |
| 車いす等の移動支援 | 緊急時・支援 | 各空港のバリアフリー案内 |

## 空港に滞在する場合

最初の選択肢は、開設確認のない自治体避難所へ独自に移動することではなく、空港係員の案内に従って空港内で安全を確保することです。その後、次の順序で確認します。

1. 空港公式通知と空港係員から、空港内待機・交通再開見込みを確認する。
2. 都道府県と空港所在地の自治体サイトで、現在の防災情報と開設中の支援施設を確認する。
3. 日本語での確認が難しい場合は、自治体の多言語情報またはJNTO訪日旅行者ホットラインを使う。

自治体の指定避難所・協定施設は、一覧に掲載されていても常時利用可能とは限りません。災害の種類と自治体の判断により開設場所が変わるため、「開設中」であることを確認できた施設だけを案内対象にします。

公式URLのSSOTは `scripts/config/official-sources.json`、画面で使う固定リンクは `src/journey-guidance.js` です。両方をテストで照合し、未承認ホストへの導線を追加できないようにします。

## 表示上の安全境界

- デモデータは実運行情報として扱わず、ファーストビューに明示する。
- GeoJSONの `normal` は「経路が利用可能」の意味にしない。「収録事象に重大情報なし」と表示する。
- バスの自動収集がない間は「公式確認が必要」と表示する。
- すべての最終判断は公式ページ、航空会社、交通事業者、行政機関へ戻す。
- JNTOホットラインは旅行支援、110・119は生命・身体に関わる緊急時のみと区別する。
