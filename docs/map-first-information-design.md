# 地図ファーストの情報設計

## 目的

空港に着いた人、空港へ向かう人、空港に滞在する人が、地図と交通状況を見ながら自分に必要な情報へ進めるようにする。

## トップページ掲載の判定基準

情報は、次の3条件をすべて満たす場合だけ地図の上に表示する。

1. 30秒以内の移動判断に使える。
2. 交通手段の選択、出発・待機の判断を変える。
3. 状態と更新時刻を裏付ける根拠がある。

初期表示の情報は以下に絞る。

- 空港と言語の選択
- 現在の状況と履歴の切り替え
- 鉄道、バス、道路、気象の表示切り替え
- 空港と主要な接続先、交通経路、影響区間を示す地図
- 空港から移動／空港へ移動／空港に滞在の選択
- 選んだ目的に対応する交通状況または滞在情報

## 初期表示から外す情報

- 全事業者の固定一覧
- 「未確認」などシステム内部の収集状態
- 詳細な情報源一覧、緯度経度、開発上の状態
- Evidence Gateの説明、免責、自治体支援の詳細

これらは詳細画面、メニュー、利用規約、または画面下部に置く。

## 鮮度のフェイルセーフ

現在データが所定の鮮度を超えた場合、運行状態を示す赤・黄・緑を地図と交通一覧から外す。地図には経路だけをグレーで残し、「現在の運行状態は表示していません」と最終更新時刻を示す。古い障害を現在の障害に見せないことを優先する。

## 390 × 844 検証条件

- 横スクロールが発生しない。
- 移動方向の3選択、地図、交通状況の要点が一続きで確認できる。
- 主操作の高さは44px以上、本文は14px以上とする。
- 日本語、英語、簡体字、繁体字、韓国語でカードが画面内に収まる。
- 古い現在データでは運行状態の色と交通状況行を表示しない。
