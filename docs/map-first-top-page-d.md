# D案：地図ファースト・トップページ

## 目的

成田空港に着いた人、成田空港へ向かう人、移動できない人が、最初の画面だけで「自分に関係する重大な障害」と「次に開く公式情報」を判断できるようにする。

## トップページ掲載の判定基準

情報は、次の3条件をすべて満たす場合だけ地図の上に表示する。

1. 30秒以内の移動判断に使える。
2. 交通手段の選択、出発・待機の判断を変える。
3. 状態と更新時刻を裏付ける根拠がある。

トップに残す情報は以下に限定する。

- 利用者の状況：空港から出たい／空港へ向かう／移動できない
- 地図：全体の交通網は薄いグレー、裏付けのある影響区間だけ赤または黄
- データ鮮度：絶対時刻と経過時間
- 最重要事象：影響が最大の1件だけ
- 次の行動：事象の公式情報を開く主ボタンと、詳細一覧への副リンク

## トップから外す情報

- 全事業者の固定一覧
- 「未確認」などシステム内部の収集状態
- 事象件数、ネットワーク色の一覧、常設の凡例
- 平常時の雨雲レイヤー、拡大縮小ボタン、緯度経度
- Evidence Gateの説明、免責、自治体支援の詳細
- 過去再生、アクセシビリティ設定、全言語ボタン

これらは詳細画面、メニュー、利用規約、または画面下部に置く。

## 鮮度のフェイルセーフ

現在データが所定の鮮度を超えた場合、運行状態を示す赤・黄・緑を地図と交通一覧から外す。地図には経路だけをグレーで残し、「現在の運行状態は表示していません」と最終更新時刻を示す。古い障害を現在の障害に見せないことを優先する。

## 390 × 844 検証条件

- 横スクロールが発生しない。
- 旅行状況の3選択、地図、鮮度、最重要事象、公式確認ボタンがスクロールせず見える。
- 主操作の高さは44px以上、本文は14px以上とする。
- 日本語、英語、簡体字、繁体字、韓国語でカードが画面内に収まる。
- 古い現在データでは運行状態の色と交通状況行を表示しない。
